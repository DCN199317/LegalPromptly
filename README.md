# LegalPromptly

This project is a simple Flask web application demonstrating a basic frontend and backend.

## Requirements

- Python 3
- pip

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python app.py
   ```

The site will be available at [http://localhost:5000](http://localhost:5000).

## Project structure

```
app.py
templates/
static/
requirements.txt
```
